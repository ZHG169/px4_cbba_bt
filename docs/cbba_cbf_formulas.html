CBBA 出價與 CBF 避碰公式

CBBA_BT 無人機端 · 2026-10-19 · 依目前程式整理（cbba_core/src/scoring.cpp、energy_model.cpp、 cbba_agent.cpp、uav_px4_bt/src/cbf.cpp、motion.cpp）。設計理由見 cbba_core/doc/formula/formula_design.md，參數見 cbba_core/doc/parameters.md、uav_px4_bt/doc/parameters.md。
兩套公式各管一層，互不影響： CBBA（任務分配）決定「哪台去哪個任務、什麼順序」，各機用出價分數競標、經 UDP 協定版本 2 達成共識； CBF（避碰）在飛行層每 50 ms 修正速度命令，保證無人機之間的水平距離，不改變任務分配。

二、CBBA 出價（每個插入位置都算一次）

① 路徑耗能（含返航）

(1) Epath = Σj∈pi ( ‖xj−1 − xj‖ · Epc + dj · Eh ) + ‖xlast − xhome‖ · Epc

線性模型。SITL 對齊 PX4 的模擬電池（依時間線性下降）：Eh = 100 / SIM_BAT_DRAIN（% / s），Epc = Eh / vcruise（cbba_uav.sh 自動算；續航 900 s、5 m/s 時 0.111 %/s、0.022 %/m）。狗是佔位值 0.05 %/s、0.1 %/m。

② 可行條件（硬限制）

(2)Bi − Epath ≥ λa　　不成立 → 這個插入位置不可行（分數 0）

另外：能力相容（無人機只接 AIR_RECON，狗只接 GROUND_INTERVENTION／PATROL）；任務要是 OPEN、沒被自己排除、沒被別台鎖定（已正式指派）。

③ 時空成本（Velhal 2022）

(3) tarrj = tdonej−1 + ‖xj−1 − xj‖ / v, tdonej = tarrj + dj
Rj = max( tcj + Dj − tnow, 1 s ), Ls,j = ‖xj−1 − xj‖, Lt,j = tarrj / Rj
CST = Σj∈pi Ls,j · Lt,j

距離 × 時間緊迫度（Lt > 1 表示到達時已過期限，仍給正分但較低）。執行中的第一個任務：有 BT 的剩餘時間時完成時間用它（目前 BT 不回報，照公式算）。

④ 總成本（電池加權）

(4) Ctotal = CST × ( 1 + w · Epath / ( Bi − λa ) )

分母用「可用電量」：電量少的那台，同樣的耗能成本放大較多 → 任務往電量多的集中。w = 1：用完可用電量時成本變兩倍。

⑤ 出價分數（邊際成本）

(5) ΔCij = min插入位置 [ Ctotal(pi ⊕ j) − Ctotal(pi) ]
scoreij = pij · valuej / ( 1 + max(ΔCij, 0) / cref )

成本 0 時分數 = value（上限）；ΔC = cref（50）時分數減半。搶占（插在最前面、取代執行中較低優先級的任務）時，比較「拿掉被搶占的任務之後」的插入前後成本（被搶占的會交回重新競標）。

⑥ 失敗過的任務：成功率（2026-10-17）

(6) pij = 1 / ( 1 + fij )　（fij：這台對任務 j 回報 TRANSIENT 的次數；只在本機、不廣播）
tarrj,eff = tarrj + ( (1 − pij) / pij ) · ( Ls,j / v + dj )

期望價值 p·value（式 5）＋期望到達時間（成功前預期失敗 (1−p)/p 次，每次「前往＋執行」），路徑後面的任務一起延後。p = 1 時還原成原公式。 例：20 m、4 m/s、執行 10 s、不算電池，失敗一次：火警（value 80、剩 30 s）75.0 → 31.6；巡檢（value 40、剩 600 s）39.9 → 19.7。

三、CBBA 共識（每台各自執行、非同步）

Bundle 建立（貪婪）

  1. 對每個可出價的任務 j，算最佳插入位置與 scoreij（式 1～6）。
  2. 出價 bidij = min( scoreij, 手上任務的最低分 )（bid warping：保證出價隨 bundle 單調不增，CBBA 收斂的條件）；搶占時不受這個上限。
  3. 能出價的條件：zj 是無人或自己，或 bidij > yj + ε（ε = 10−3），或平手且自己的機號較小。
  4. 挑實際分數最高的加入 bundle、插進路徑；重複直到沒有可加的或 bundle 滿（max_bundle 5）。

共識消解（Choi 2009 的 17 條規則）

收到鄰居 k 的（ykj, zkj, sk）後，依「雙方各認為誰得標」與時間戳 s（各機最後一次取得某載具資訊的時間）決定 更新／重設／不變； 自己的任務被拿走時，連鎖退標：它和之後加入 bundle 的任務都釋放，再重新出價。案例表在 cbba_rule_cases.csv。

四、CBF 避碰（無人機飛行層，每 50 ms）

輸入：自己的位置 p、目標 g；鄰機 j 的位置 pj、速度 vj、是否執行任務中（BT 的位置廣播，UDP 14601、10 Hz； 位置用速度外推 age 秒，最多 max_extrapolation 0.5 s；超過 neighbor_timeout 1 s 沒更新的不算）。輸出：速度命令 u（map ENU）。

① 名目速度（直線朝目標）

(7) unom = ( g − p ) / ‖g − p‖ · min( V, katt ‖g − p‖, √(2 ab ‖g − p‖) )
垂直分量另外限制在 √(2 abv |Δz|)（整個向量等比例縮小）

V = cruise_speed；katt = cbf.k_att 1.0 1/s；ab = cbf.brake_accel 0.2 m/s²；abv = cbf.brake_vertical_accel 0.1 m/s²。

② 障礙函數與約束（只看水平）

(8) hj = ‖p − pj‖² − r²　（h ≥ 0 = 安全）
要求　ḣj ≥ −ρ γ hj，　ḣj = 2 (p − pj) · (u − vj)
⇒　aj · u ≥ bj，　aj = 2 (p − pj)，　bj = λ · aj · vj − ρ γ hj

只對 cbf.influence_radius 內的鄰機加約束；只限制「往鄰機靠近」的速度，平行飛、遠離不受影響；懸停（u = 0）在 h ≥ 0 時已滿足，不會被推。

③ 往右繞、求解

(9) unom′ = unom + ktan · ( bj − aj·unom ) / ‖aj‖ · eright　（只對被違反的約束）
u = argminu ‖u − unom′‖²　s.t.　aj · u ≥ bj，∀j　（水平 2D，Dykstra 交替投影）

ktan = cbf.k_tan 0.8：正對面飛來時單純的 CBF 只會減速到停（死結），全隊都往自己的右手邊繞就會錯開。 垂直速度用名目值、限制在 max_vertical_speed；總和限制在 V。

④ 推導量（ρ = 0.5、單一鄰機）

量公式
距離 d 時允許往鄰機靠近的速度c(d) = ρ γ (d² − r²) / (2d)
γ 的上限（剎得住）γ ≤ 2 · motion.max_accel / (ρ · V)
influence_radius 的下限（一進範圍不急剎）R ≥ ( V + √(V² + (ρ γ r)²) ) / (ρ γ)　→ V = 0.5 m/s：2.4 m（yaml 3 m）；V = 3 m/s：12.1 m（itest demo 12 m）
讓路時退到的距離（鄰機以 v 飛過來）d² − 2d v / γ − yield_radius² = 0 的正根

⑤ 運動平滑層 → PX4

u 不直接給 PX4：參考速度往 u 靠近，水平加速度 ≤ motion.max_accel 1.5 m/s²、垂直 ≤ 1.0 m/s²；參考位置最多領先實際位置 motion.leash 1.5 m；離目標 < motion.hold_radius 0.2 m 且沒有鄰機要閃時直接交給 PX4 位置保持。輸出位置＋速度前饋（offboard TrajectorySetpoint）。 到達判定：離目標 < reach_tolerance 0.25 m。
