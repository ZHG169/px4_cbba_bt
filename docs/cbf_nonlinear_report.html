多無人機避碰：控制障礙函數的設計與驗證

CBBA_BT 無人機端 · 2026-10-25 · 以非線性控制的觀點整理目前的實作（uav_px4_bt/src/avoidance.cpp、 cbf.cpp、motion.cpp）。參數見 uav_px4_bt/doc/parameters.md 第五節；驗證在 PX4 SITL＋Gazebo（yard 場景）。
摘要　多台旋翼機在同一高度執行 CBBA 分配的任務，航線交會時要同時滿足兩個要求：安全（任兩台水平距離不小於 r = 1 m）與活性（不互相卡住、不停下來等）。安全由二階控制障礙函數（CBF）負責：以剎車距離定義安全集合， 在加速度層用二次規劃（QP）做最小修正，保證安全集合前向不變。純 CBF-QP 在對飛、交叉時會產生不想要的平衡點（互相減速到停）， 所以在 CBF 之前加一層監督式的名目控制：預測衝突、用唯一的路權決定誰讓、讓的那台用速度障礙（VO）轉向繞行。 這一層只影響「往哪裡飛」，不影響安全保證。PX4 SITL 在 3 m/s 下驗證：交會時讓行的一台提早轉向、最近距離 2.25 m、不停頓。

1. 系統模型

每台無人機 i 的水平運動（高度由另一個迴路維持在巡檢高度）視為受加速度限制的二階積分器：

ṗi = vi,　v̇i = ai,　‖ai‖ ≤ amax = 1.5 m/s²,　‖vi‖ ≤ V(1)

寫成控制仿射形式 ẋ = f(x) + g(x) u，狀態 x = (p, v) ∈ ℝ⁴、輸入 u = a ∈ 𝒰 = {‖a‖ ≤ amax}。 實際的致動器是 PX4 的位置控制器：程式送出參考位置 pref 與速度前饋 vref，PX4 追蹤它們；我們的控制量 a 積分成 vref、pref（運動平滑層，加速度上限同樣是 amax），因此 (1) 的輸入限制和實際送出的命令一致。 PX4 追蹤與位置廣播（10 Hz、mesh 延遲）合成的反應延遲記為 τ ≈ 0.3 s，在第 6 節用安全距離的餘量處理。

鄰機 j 的狀態只透過位置廣播取得（機號、位置、速度、旗標「執行中」「任務中懸停」），位置用速度外推收到後經過的時間。 記相對量 Δp = pi − pj、Δv = vi − vj、d = ‖Δp‖、n = Δp / d、 ḋ = nᵀΔv（< 0 表示正在靠近）。

2. 安全集合與控制障礙函數

安全的定義是任兩台的水平距離不小於 r：𝒮 = {x : d ≥ r}。控制問題是找一個回授 u = k(x)，讓閉迴路的軌跡從安全的 初始狀態出發後永遠留在安全集合裡（前向不變，forward invariance）。

定義（控制障礙函數，Ames 等 2017）　連續可微的 h(x) 定義集合 𝒞 = {x : h(x) ≥ 0}。若存在擴展 𝒦 類函數 α，使得
supu∈𝒰 [ Lfh(x) + Lgh(x) u ] ≥ −α(h(x))　對所有 x ∈ 𝒞(2)
則 h 是 CBF；任何滿足 ḣ ≥ −α(h) 的 Lipschitz 回授都讓 𝒞 前向不變（由 Nagumo 定理）。我們取 α(h) = γh。

2.1 為什麼不能直接用距離平方

直覺的選擇 h0 = d² − r² 對加速度的相對階數是 2：ḣ0 = 2ΔpᵀΔv 不含 a（Lgh0 = 0）， 條件 (2) 無法透過 a 滿足。早期的實作把速度當輸入（一階積分器 ṗ = u），在 h0 上直接加約束；但實際的速度要經過加速度限制才能改變， 3 m/s 時剎停要約 3 m，比 r 還長，模型與實際不符時保證就失效（SITL 量到最近 0.88 m）。另外 h0 只看距離、不看方向， 路線本來會錯開 2.36 m 的錯身也被砍速度。高相對階數的一般解法是指數 CBF／高階 CBF（Nguyen & Sreenath 2016、Xiao & Belta 2019）； 我們採用多機器人文獻中物理意義較清楚的「剎車距離」障礙函數（Wang、Ames、Egerstedt 2017）。

3. 二階障礙函數（剎車距離）

h(x) = √( 2A (d − r) ) + ḋ(3)

意義：A 是兩台可用的相對減速度。h ≥ 0 等價於「靠近速度 −ḋ ≤ √(2A(d − r))」， 也就是現在立刻以 A 全力剎車，靠近速度會在距離縮到 r 之前歸零（等加速度運動 s² = 2A·距離）。 所以 𝒞 = {h ≥ 0} ⊂ 𝒮，而且是「還剎得住」的狀態集合，比 𝒮 保守，速度越快越保守。

3.1 對加速度的相對階數為 1

對時間微分（d > r）：

d̈ = nᵀΔa + ( ‖Δv‖² − ḋ² ) / d,　　ḣ = nᵀΔa + ( ‖Δv‖² − ḋ² ) / d + A ḋ / √( 2A(d − r) )(4)

第二項是相對速度的切向分量造成的「離心」項（恆 ≥ 0，錯身時幫助安全）；第三項在靠近時為負。Δa = ai − aj 出現在 ḣ 中，Lgh = nᵀ ≠ 0，相對階數為 1，條件 ḣ ≥ −γh 是 a 的線性不等式：

nᵀ(ai − aj) ≥ b := −( ‖Δv‖² − ḋ² ) / d − A ḋ / √( 2A(d − r) ) − γ h(5)

3.2 可行性（單一鄰機）

只有一台鄰機時，(5) 在 𝒰 裡有解若且唯若 b ≤ amax（取 a = amax n）。在 𝒞 的內部與邊界附近，A 取 不超過實際能提供的減速度時，全力剎車就讓 h 不再下降，條件 (2) 成立。多台鄰機加上輸入限制時，各約束不一定同時可行（第 5 節）。

4. 分散式：責任分配

(5) 含有對方的加速度 aj，各機不知道。做法是把需要的相對加速度分給兩台：機 i 負責 ρi、機 j 負責 ρj， ρi + ρj = 1：

nᵀai ≥ ρi b,　　−nᵀaj ≥ ρj b　⟹　nᵀΔa ≥ b,　　A = amax / ρi(6)

兩台各自滿足自己的那一份，合起來就是 (5)。可用的相對減速度隨之改變：各分一半時兩台一起剎，A = 2amax；全額負責時只有自己剎， A = amax。ρ 的選擇（只用位置廣播的資料，兩台算出來互補）：

情況ρi理由
自己是讓的那台（第 7 節的路權）1直行的那台照原路線，安全由讓的那台全額負責
對方沒有在靠近（往自己的速度 < 0.2 m/s：懸停或正在離開）1對方不會替自己剎那一半；只假設它會分擔時，3 m/s 下單元測試量到 0.57 m
兩台都在靠近0.5對稱分攤，兩台一起剎

ρ 是「自己分到多少相對加速度的責任」，不是「讓多少」：它決定約束多緊，不決定往哪邊繞。方向由第 7 節的監督層決定。

5. CBF-QP 與無解時的處理

每個控制週期（20 Hz）解：

a* = argmina ‖a − aref‖²　s.t.　nₖᵀa ≥ ρₖ bₖ（每台需要的鄰機 k），　‖a‖ ≤ amax(7)

可行域是半平面與圓盤的交集，是凸的二維 QP，用 Dykstra 交替投影求解（鄰機只有幾台，迭代很快）。aref 是監督層想要的速度換成的加速度： aref = (uref − vref) / Δt，限制在 amax；求得的 a* 積分回 vref + a*Δt 交給運動平滑層。 因為 ‖a*‖ ≤ amax 就是平滑層的加速度上限，送給 PX4 的命令就是 QP 的解，不會再被平滑層改掉（一階版本的問題之一）。

可行性不保證：多個約束加上輸入限制可能沒有交集（例如一台被夾在兩台之間、背後無路可退）。這時不使用投影的近似解，改成緊急處理： 在 ‖a‖ = amax 的 48 個方向中，選讓所有約束的最小餘裕 minₖ(nₖᵀa − ρₖbₖ) 最大的方向，也就是近似解 max-min 問題。 只看「離最近那台遠一點」時，最近的是停著的鄰機，會被推向另一台高速飛來的（單元測試 0.31 m），所以必須考慮全部約束。

CBF-QP 只看當下的狀態，無法預先避免「幾秒後無解」。在起降區這種密集的地方，我們用場景的設定（停機點間隔 5 m，大於 3 m/s 的剎車距離約 3.9 m） 讓系統留在可行的範圍，而不是在 QP 上增加規則。要從根本處理需要預測整段軌跡，也就是 MPC 或 MPC-CBF，列為後續工作。

6. 延遲與量測的穩健性

CBF 的保證假設控制量立即作用。實際上 PX4 追蹤、位置廣播共有約 τ = 0.3 s 的延遲，這段時間仍以原速度靠近。處理方式是把安全距離收緊（集合往內縮）：

reff = r + τ · max(0, −ḋ),　　剎車餘裕 m = d − r − τ·(−ḋ)+ − (−ḋ)+² / (2A)(8)

(3) 中的 r 用 reff 代替。m ≥ 0 與 h ≥ 0 等價（同一個水平集），m 有長度的單位、好解釋，用來決定何時啟用約束（第 7.3 節）。 安全計算用實際量到的位置與速度（PX4 落後時照真實狀態保守處理），積分則從參考速度 vref 開始（命令平順）。 這是工程上的餘量，不是對延遲的嚴格證明（嚴格的做法如 input-to-state safety，列為後續）。

7. 活性：監督式名目控制

CBF-QP 是最小修正：只拿掉 aref 朝向不安全的分量。兩台正對面飛時，最小修正就是沿連線減速，系統收斂到兩台都停住的平衡點； 這是 CBF-QP 已知會引入不想要的漸近穩定平衡點的性質（Reis 等 2021），多機器人的「死結」（Grover 等 2020）。安全由 CBF 保證，但不停頓要靠名目控制器。 我們在 CBF 之前加一層監督式控制，只決定 aref：

每台鄰機，每個週期：
① 預測會不會碰（有限時間的最近點，CPA）── 不會：不比路權、不繞、不加 CBF 約束（距離或剎車餘裕不夠時例外）
② 會：路權鍵 K = (任務中懸停, 執行中, −機號)，大的直行、小的讓
③ 讓的那台：VO 找離 u_nom 最近的安全速度（先只轉方向，左右一樣時往右；找不到才降速）
④ 角色、方向鎖定到已經通過且距離變大（遲滯）
⑤ 第 5 節的 CBF-QP 保底；無解 → 緊急

7.1 衝突預測

自己用名目速度 unom（意圖，例如剛接到任務、還沒加速時），鄰機用廣播的速度；只看有限時間、而且不外推到自己的目標之後：

vr = unom − vj,　t* = clamp( −Δpᵀvr / ‖vr‖², 0, T ),　d* = ‖Δp + vrt*‖,　T = min(5 s, 到目標的時間)(9)

正在靠近而且 d* < dmiss 才算衝突（0.5 m/s 時 1.5 m，3 m/s 時 2.1 m）。最近點恰好是抵達自己目標的那一刻（目標就在鄰機旁，例如停機點）時， 只要求 r：不要求做不到的距離，否則會一直繞（SITL 曾因此相撞）。用意圖而不是量測速度，是因為剛起步的那台量到的速度是 0， 等量得到時已經太近（SITL 0.88 m 的原因）。

7.2 路權：讓對稱性破缺

兩台用同一份位置廣播計算字典序的路權鍵 K = (任務中懸停, 執行中, −機號)，因為 K 是全序、機號唯一，對任何一對都恰好一台直行、一台讓， 不會兩台都等、也不會都不讓。這就是打破正對面這種對稱情況、避開死結平衡點的機制。「任務中懸停」由 BT 的狀態產生（已到任務點、正在辨識或監控）， 不是用速度猜，避免剛起步、減速被誤判。開始交會後角色與繞行方向鎖定，直到已經通過且距離連續變大才解除；這是遲滯，避免在邊界附近來回切換角色 （類似 Zeno 式的高頻切換）。

7.3 VO 繞行與約束的啟用

讓的那台在速度空間找 uref：保持速度、轉最小的角度，使對所有鄰機的預測最近距離都夠遠（速度障礙的概念，Fiorini & Shiller 1998）； 讓行一定是轉向，不是設成零速度。停著的那台要讓時，側移速度只要「剛好來得及」= 1.5 × 需要的側移 / 交會前的時間。

CBF 約束只對需要的鄰機啟用：預測會衝突、距離 < 1.3 m、或剎車餘裕 m < 0.5 m。因為 m 與 h 是同一個水平集， 「m < 0.5 m 就啟用」表示在 ∂𝒞 的一個鄰域內約束一定開著，前向不變的論證仍然成立；遠離邊界時不加約束，路線本來會錯開的錯身就不會被砍速度。

10. 限制與後續

  • 可行性：多約束＋輸入限制的相容性不保證（第 5 節）；密集區用場景設定避免。後續：MPC-CBF，或依可行性設計 ρ。
  • 延遲：τ 用安全距離的餘量處理，沒有嚴格證明；後續可用 input-to-state safety 或把延遲納入模型。
  • 非合作鄰機：不跑這套的鄰機（被人工接管、PX4 自己返航）沒有位置廣播的狀態，當成待命；不會替自己分擔的情況由 ρ = 1 涵蓋（對方沒有在靠近時）。
  • 保守性：(3) 只看連線方向。兩台約 6 m/s 相對速度對飛時，讓的那台在 14 m 外就判成剎不住而短暫觸發緊急（VO 已經讓航線錯開，不危險）。
  • 更高速：實驗規劃的 8～12 m/s 時剎車距離約 30～60 m，水平避碰的作用範圍涵蓋大半個場地，建議改用不同高度分層，水平 CBF 只用在任務點附近。
