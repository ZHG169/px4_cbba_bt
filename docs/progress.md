## 二、最近的測試結果（2026-10-11，隔離的 docker 環境，3 台）

**itest comm（CBBA 之間的通訊）**：8 過、1 敗

| 項目 | 結果 |
|---|---|
| C0 節點上線、C1 只有一台得標（602 ms）、C2 完成（50 ms 撤下）、C3 失敗交回（652 ms）、C4 停送狀態 → 接手（2.2 s）、C6 重開機、C7 掉包 30%、C8 斷網 | 通過 |
| C5 節點整個停止 → 接手 | 失敗：失聯接手還沒實作（預期） |
| M 待命時 mesh 流量 | 約 69 kB/s，大部分是漏到 mesh 的 DDS |

**itest uav（UAV 整串）**：6 項全過 —— 起飛、單一任務、火警（1.83 s、誤差 0.41 m）、誘餌不觸發、三台分配、
飛行中 PX4 斷線 → 2.7 s 別台接手並完成。

測試中修掉的：停止參與的節點不送紀錄，飛行中 PX4 斷線時任務卡住（A1）；`px4_sitl.sh` 第 2 台起要設 `CBBA_WORLD`。
